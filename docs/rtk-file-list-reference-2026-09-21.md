- `ls` 只解析可确认的 POSIX 长列表，保留文件名、目录、权限和大小；未知语言环境与失败文本透传。

- `find`/`fd` 只分组纯路径输出；空字符格式、结构化格式、执行/删除动作和失败文本透传。
