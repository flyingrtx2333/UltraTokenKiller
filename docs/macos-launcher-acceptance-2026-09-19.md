## 路由丢失原因与修复

在这台机器的 Codex 0.153.4 中，子命令前后同时出现 `-c` 时，前面的配置会丢失。零模型调用的 `config/read` 实测：前置 `model_provider=openai` 返回原有 `headroom`，后置则返回 `openai`。

启动器现在把配置参数统一放在最终子命令作用域，保留用户参数顺序，再应用 UTK 受管配置；`--` 后的文字保持原样。启动模型前额外读取有效配置，核对模型路由、目标 URL 和 MCP 会话绑定。不一致即停止。未验证的提供商/profile 切换参数被拒绝。

Mac 自动本地通信仅覆盖已经验证的基础权限配置，使用仅允许 UTK socket 的代理规则，保留只读或工作区文件权限。旧 sandbox、自定义 profile 或已有网络代理配置明确拒绝自动适配，不删除原限制。
