# UltraTokenKiller brand assets

The selected mark is **B: Context Compression Gate**. Two code brackets compress
token bars toward a compact central core.

## Files

- `utk-icon.svg`: primary transparent vector icon.
- `utk-icon-mono.svg`: single-color vector icon for light backgrounds.
- `utk-lockup.svg`: horizontal icon and wordmark.
- `utk-lockup-light.svg`: horizontal lockup with sufficient contrast on light backgrounds.
- `utk-icon-{16,32,64,256,512,1024}.png`: transparent raster exports.
- `utk-lockup-860.png`: transparent horizontal raster export.

## Colors

- Background: `#091016`
- Mint teal: `#38D4A7`
- Off-white: `#E9F0F4`
- Slate: `#263440`

Keep clear space around the mark equal to the width of its center vertical bar.
At 16 px, use the icon without the wordmark. Do not add gradients, rotate the
mark, or place it on a low-contrast mint background.
